## F-1 · One variable, two statements

Exhibit A quotes the definition of rating_decline from two places in the manuscript: the body of
§4.1.1 and the note to Table 1.

1. Write each quotation as an inequality.
2. Apply both definitions to the same pair of values in the same week (t−1). What happens?
3. When you read this variable's coefficient, which definition are you assuming? Can the manuscript
   settle that on its own? If it cannot, what else would be needed?

## F-2 · When a correlation and a coefficient disagree

In Exhibit E Table 3, the simple correlation between reply_speed and review_count is −0.150.
In Exhibit B Table 4, the regression coefficient on reply_speed is 0.032.

1. The two numbers answer different questions. State each question.
2. What does the fixed-effects panel model hold constant that a simple correlation does not?
3. Could you use −0.150 to tell a practitioner that replying faster reduces reviews?

## F-3 · Reading a main effect when an interaction is present

In Exhibit C Table 5, the main effect of reply_speed is −0.027 and is not significant.
In the same table, reply_count × reply_speed is 0.027 and is significant.

1. Under what condition does the main effect of −0.027 describe the effect of reply_speed?
2. Judge whether that condition is observable in this data at all.
3. Can "replying faster does not help" be concluded from this table alone?
4. The two values share their digits, −0.027 and 0.027. Decide whether that means anything.

## F-4 · When the sample size has two values

The ⚠ block in Exhibit A records two motel counts, and the observation count appears at two stages.

1. Using Exhibit A, note where in the manuscript each value comes from.
2. Can the manuscript settle which motel count is the analysis sample?
3. Does the manuscript state the rule that took the observations from 35,465 to 26,734?
4. As a reviewer, what would you ask the authors for? Write the request as a sentence.

## F-5 · Reporting a hypothesis that was not supported

In Exhibit D Table 6, Model 4, the coefficient on rating_decline × reply_speed is −0.013 and is not
significant.

1. Report this result in one sentence. Decide whether the sign belongs in your conclusion, and let
   that decision show in the sentence.
2. Does this result support the prescription "reply faster in weeks when ratings fall"?
3. Explain the difference between these two sentences:
   - The prescription is wrong.
   - This evidence cannot speak to the prescription.
4. Which would you write in a practitioner report? Give your reason.

## F-6 · The limits of a proxy

The manuscript measures a property's success by its weekly review count. Exhibit A quotes both the
justification and the limitation.

1. State the assumption that must hold for review count to proxy for bookings.
2. Give one situation in which that assumption breaks.
3. Which conclusion in this case leans hardest on that assumption?
