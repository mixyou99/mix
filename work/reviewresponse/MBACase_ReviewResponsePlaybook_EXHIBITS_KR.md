**고객평점하락의 정의 — 원고에 두 표기가 있다**

> **4.1.1 본문**: 누적평균평점 − 당주 평균평점이 **0보다 클 경우 1**, 반대의 경우 0
> **표 1 설명**: (누적평균평점) − (평균평점)이 **음수일 경우 1**, 아닐 경우 0

같은 뺄셈에 부호 조건이 뒤집혀 있다. **본 Exhibit은 이 불일치를 해소하지 않는다.**

**코로나확진자 — 원고에 두 표기가 있다**

> **표 1**: "숙박시설 *i*의 t−1주의 신규 코로나19 확진자 수"
> **본문 4.1.1**: "t−1주의 **국내** 코로나19 신규 확진자 수를 활용하여 … 통제하였다(코로나확진자 [i, t])"

변수 첨자는 `[i, t]`. **본 Exhibit은 이 불일치도 해소하지 않는다.**

**성공의 조작화 (원고 5.3 한계)**

> 리뷰 수는 예약 건수의 **대리지표**로 쓴다(Ye et al. 2009, 2011). 실제 방문자 수·매출은 관측되지 않았다.

**모형** (패널 고정효과 · OLS · 강건표준오차)

```
ln(리뷰수 [i,t]) = b0
                 + b1 · ln(답변수    [i, t−1])
                 + b2 · ln(답변속도  [i, t−1])
                 + b3 · 고객평점하락 [i, t−1]
                 + d  · 통제        [i, t−1]
                 + theta(t) + mu(i) + eps(i,t)
```

`mu(i)` = 시설 고정효과. `theta(t)` = 시간 고정효과.
