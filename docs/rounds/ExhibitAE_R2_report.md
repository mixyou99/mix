## 6 · 도구 쪽에서 나온 것

이번 라운드에 게이트 결함 **6건**을 찾아 고쳤다. 전부 산출물이 아니라 검사식을 고쳤고
정정 이력을 `gate_exhibit.py` 의 `검사식 예외 이력` 블록에 남겼다.

1. **f-string 표현부 역슬래시** — 반입본이 이 수리를 **되돌린 채로** 왔다.
   README_RESTART §3은 반영됐다고 적었으나 실물은 아니었다. Python 3.11에서 파일 전체가
   파싱되지 않아 8개 게이트 전부 도달 불가였다. 같은 자리 두 번째라 이력에 재등록으로 남겼다.
2. **E-G9 ⚠ 인라인 포인터 오탐** · 3. **E-G9 병치 라벨 정규화** (위 §3)
4. **docx 모드에서 `line_role` 사망** — `load()` 가 문서를 한 줄로 만들어 표 행 판정 장치가
   docx 경로에서 한 번도 동작하지 않았다. PDF 경로에만 줄이 있었다.
5. **`T_ROW` 가 옛 열 구성 전제** — D-5·D-8이 바꾼 배치를 못 따라갔다. 산출물이 옳고 검사식이 낡았다.
6. **사유 정규식이 한국어 전용** — `T1_VARS`에 EN 변수명이 없어 **EN 표 행이 하나도 안 잡혔고**,
   `(4, 5, 6)`·`1–5 stars`·`Section 4.1`·`Row/column indices` 가 전부 빠졌다.

   **6번은 EN을 처음 E-G7에 걸어서 드러났다.** KR만 돌리면 언어 비대칭 결함은 영원히 보이지 않는다.
   P-1이 두 판을 다 재측정하라고 요구하는 이유가 이것이다.
