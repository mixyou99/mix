## 1 · 지시서 정정 3건

### 정정 1 — D-5 열 구성

지시서가 `역할 | 변수 | 설명 | N | 평균(표준편차) | 최소값(최대값)` 이라 적었으나,
**원 논문 표 1의 첫 열에는 머리글이 없다.** `역할`은 원문에 없는 말이다.

```
머리글 행은 다섯 칸이다. 첫 열에 머리글이 없다.
   (머리글 없음) | 변수 | 설명 | N | 평균(표준편차) | 최소값(최대값)
캡션: <표 1> 주요 연구변수에 대한 기술통계
'통제변수'는 아래 두 행에 걸친 병합 셀이다.
```

D-5 자체가 "축약·정돈 금지"를 요구하는 항목인데 지시서가 원문에 없는 머리글을
넣으라고 한 것이다. D-2가 지적한 것과 같은 유형의 결함이다.

### 정정 2 — D-5 설명 열 여섯 셀 전문

지시서에는 두 셀만 실려 있었다. 나머지 넷을 원 논문에서 확보했다.
**원문 그대로 옮긴다. 축약·정돈 금지.**

| 첫 열 | 변수 | 설명 (원문) |
|---|---|---|
| 성공 | 리뷰수 | `숙박시설 i에서 발생한 t주의 리뷰 수` |
| 적극성 | 답변수 | `숙박시설 i의 부정적 리뷰에 대해 t-1 주에 발생한 호스트의 답변수` |
| 적시성 | 답변속도 | `1/(숙박시설 i의 부정적 리뷰 발생 후 t-1주에 발생한 호스트 답변이 발생하기까지 평균 일수+1)` |
| 평판하락 | 고객평점하락 | `(숙박시설 i의 t-1주의 누적평균평점) - (숙박시설 i의 t-1주의 평균평점)이 음수일 경우 1, 아닐 경우 0` |
| 통제변수 | 누적리뷰수 | `숙박시설 i의 t-1주의 누적 리뷰 수` |
| 통제변수 | 코로나확진자 | `숙박시설 i의 t-1주의 신규 코로나19 확진자 수` |

N은 여섯 행 모두 `26,734`.
통계값: `16.806 (16.436) / 0 (149)` · `9.118 (13.544) / 0 (285)` · `0.836 (0.257) / 0.005 (1)` ·
`0.451 (0.498) / 0 (1)` · `3,301.352 (3,092.939) / 2 (19,552)` · `6,791.309 (4313.618) / 2,630 (16,934)`

**원문의 흔들림 넷 — 그대로 보존한다. 고치면 원문 전재가 아니다.**

1. `t-1 주` (답변수 설명만 띄어씀) vs `t-1주` (나머지 다섯)
2. `(4313.618)` — 코로나확진자 SD에만 천 단위 쉼표가 없다. 같은 표의 누적리뷰수는 `(3,092.939)`
3. 답변속도 최대값 `(1)` — 소수 자릿수 없이
4. 첫 열 머리글 없음

## 2 · E-G9 실패 두 건 — 처리 방침

Cowork가 (b)+(a) 조합을 제안했다. 동의한다. **다만 순서가 (b) → (a) 다.**

### (b) 먼저 — 검사식 정정 (G2′)

**병치 인용 KR 2 vs EN 3 은 오탐이다.** EN 에서 `§4.1.1 body` 와 `Table 1 note` 가
정규식 양쪽에 걸렸다. 검사식이 EN 태그를 정규화하지 못한 것이지 실물 불균형이 아니다.

**D-4 의 인라인 ⚠ 마커도 오탐 쪽이다.** `위 ⚠ 참조` 는 블록이 아니라 포인터다.
**블록 도입 마커만 세고 인라인 참조는 제외**하도록 고친다.

정정 이력을 `gate_exhibit.py` 의 `검사식 예외 이력` 블록에 같은 형식으로 남길 것.

### (a) 그다음 — 실물 수정

**⚠ 개수 KR 5 vs EN 4 중 D-2 몫은 진짜다.** D-2 가 KR 에만
"원고는 35,465와 26,734를 모두 '최종적으로' 서술한다" 문장을 넣었다. EN 에도 넣는다.

### 순서를 뒤집으면 안 되는 이유

(a) 를 먼저 하면 오탐이 남은 상태로 EN 을 손대게 되고, 진짜 불균형을 고쳤는지
오탐을 우회했는지 구분되지 않는다. (b) 로 검사식을 정리한 뒤 재측정하면
**남는 신호가 곧 진짜 결함**이다.

**(c) 는 받지 않는다.** 예외로 문서화하면 다음에 진짜 불균형이 생겼을 때 같은 자리에서
또 통과한다.
