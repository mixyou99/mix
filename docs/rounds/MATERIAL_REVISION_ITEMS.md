# KMB689 자료 수정 필요 항목

작성: 2026-09-11
상태: 교수 확인 대기 · 원본 자료 미수정

## 0 · 판정 기준

기법 세션의 2.2 강사 시연은 `함정의 냄새만 맡게 하고 정답은 주지 않는다`는 선언과 실제 발화를 함께
대조한다. 질문 직후 핵심 판정·정답 수치·행동 결론을 말하면, 덱이 질문에서 멈춰도 대본대로 진행하는 순간
학생 발견 구간 2.3이 무력화된다. 답은 2.4 회수·결정으로 늦춘다.

이 문서는 수정 필요 위치와 수정 방향만 기록한다. 교수 자료인 강사 대본 자체는 고치지 않는다.

Wk12는 정답 키 파일만 감추면 된다고 좁게 해석한 탓에 핵심 판정 자체가 2.2에 남아 있다. 2.4
`MBA_S12_Discussion_Prompts_INSTRUCTOR_KR.md`는 학생이 이미 `정보 질=관련성`, Smart #3 과잉 해석을
찾은 뒤 진행하도록 명시하므로, 현재 대본은 그 공개 순서와 충돌한다.

## 3 · Wk13 연관규칙 — 같은 유형, 수정 필요

Wk13의 2.4 `MBA_S13_Discussion_Prompts_INSTRUCTOR_KR.md`는 학생이 향상도<1 오독과
강함≠실행가능성을 이미 발견한 상태를 전제로 한다. 현재 대본은 두 답과 네 규칙의 처리까지 2.2에서 먼저
말하므로 같은 내부 모순이다.

## 4 · 교수 확인 항목

1. Wk11·Wk12·Wk13 강사 대본의 답 문구를 2.4 토론 자료로 이동할지.
2. 2.2 대본을 질문형 무답판으로 분리할지, 기존 파일 안에서 시연·회수 구간을 재배치할지.
3. 수정 전까지는 각 덱의 2.2 질문-멈춤 슬라이드를 운영 정본으로 삼고, 대본의 위 표 줄을 읽지 않는다는
   임시 운영 규칙을 승인할지.
