## 1 · 열 구성 (원문)

머리글 행은 다섯 칸만 인쇄된다 — **역할 열에는 머리글이 없다.**

```
(머리글 없음) | 변수 | 설명 | N | 평균(표준편차) | 최소값(최대값)
```

R2 지시서가 적은 `역할 | 변수 | 설명 | N | 평균(표준편차) | 최소값(최대값)` 과 실제 열 수는 같고,
첫 열에 머리글 문자열이 없다는 점만 다르다. 복원 시 이 점을 임의로 채우지 말 것.

## 3 · 원문의 표기 흔들림 — 정돈하지 말 것

D-5는 `축약·정돈 금지` 다. 아래는 원문의 불일치이며 **그대로 옮겨야 한다.**

1. **`t-1 주` vs `t-1주`** — 답변수 설명만 `t-1 주` 로 띄어 쓴다. 나머지 다섯은 붙여 쓴다.
2. **`(4313.618)` vs `(3,092.939)`** — 코로나확진자 표준편차에만 천 단위 쉼표가 없다.
   같은 표 안에서 누적리뷰수는 쉼표를 쓴다.
3. **역할 열 머리글 없음** — 위 §1 참조.
4. **답변속도 최대값이 `(1)`** — 다른 최대값과 달리 소수 자릿수가 없다.

## 4 · 곁가지로 확인된 것 (D-4·D-9 근거)

D-9가 병치용으로 지정한 두 문구를 원 논문에서 직접 확인했다. **둘 다 원문에 그대로 있다.**

- **4.1.1 본문**: `고객평점하락it-1은 숙박시설i에 대하여 t-1주의 누적평균평점에서 t-1주에 발생한
  리뷰의 평균평점을 제한 값이 0보다 클 경우에 1이고 반대의 경우에 0을 가지는 이변량 변수이다.`
- **표 1 설명**: 위 §2의 고객평점하락 행.

두 문구는 **부호가 반대다** — 본문은 `0보다 클 경우 1`, 표 1은 `음수일 경우 1`. 이것이 S2-1′의 교육 재료다.

D-4 관련해서도 4.2.1 서술을 확인했다 — `본 연구모형에서 통제변수 및 설명변수는 숙박시설 i의
t-1번째 주에 발생한 사건들이며`. 재검수 문서(D-4)의 실측과 일치한다.

## 5 · D-5에 미치는 영향

R2 착수 보고에서 D-5를 "두 겹으로 막혀 있다"고 적었다. **그중 한 겹이 풀렸다.**

| 열 | 이전 판정 | 현재 |
|---|---|---|
| 설명 (리뷰수·답변수·답변속도·누적리뷰수) | 4/6 불가 — 원 논문 부재 | **확보** (위 §2) |
| 설명 (고객평점하락·코로나확진자) | 지시서에 제시 | 원문과 일치 확인 |
| 역할·변수·N·통계값 | 복원 가능 | 원문으로 재확인 |

남은 한 겹은 그대로다 — **편집 대상인 Exhibit A·E KR·EN 산출물이 여전히 부재다.**
표 1을 어디에 복원할 문서가 없다. D-5는 아직 실행 불가이며, R2 착수 조건도 그대로다.
