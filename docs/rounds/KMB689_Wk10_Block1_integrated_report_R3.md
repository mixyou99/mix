## 원문 보존 게이트 정정과 검출력 대조군

**⚠ 오탐 정정 (2026-09-10):** 최초 검사식은 `<a:t>` 요소 배열을 그대로 대조했다. PowerPoint는
편집·저장 과정에서 런을 쪼개거나 합치므로 요소 개수는 보존되지 않는다. 재사용 슬라이드 10·14에서
화면에 보이지 않는 끝의 U+00A0가 각각 1건 누락된 것을 실질 실패로 잘못 판정해 전건 롤백했다.

G2′에 따라 산출물을 고치지 않고 검사식을 다음과 같이 정정했다.

1. 슬라이드별 `<a:t>`를 순서대로 모두 이어붙인다.
2. U+00A0를 U+0020으로 바꾼다.
3. 줄바꿈·탭을 공백으로 바꾼다.
4. 연속 ASCII 공백을 하나로 줄이고 앞뒤 ASCII 공백을 제거한다.
5. 숫자·별표·기호·구두점·문자·순서는 그대로 대조한다.

검출력 대조군은 실제 재사용 원문 코퍼스에 변이를 주어 실행했다.

| 대조군 | 기대 | 결과 |
|---|---:|---:|
| U+00A0·탭·줄바꿈·연속 공백만 변경 | 허용 | 허용 |
| 단어 삭제 | 검출 | 검출 |
| 숫자 변경 | 검출 | 검출 |
| 구두점 삭제 | 검출 | 검출 |

따라서 정정한 검사식은 화면에 영향 없는 형식 차이를 제외하면서 실질 내용 변경을 계속 검출한다.

대조군 최초 실행은 원본 4번 한 장에 숫자 표본이 없어 실행 전제에서 중단됐다. 덱 판정에는 도달하지 않았고,
실제 재사용 원문 13장 코퍼스에서 표본을 고르도록 검사기만 정정했다. PPTX의 SHA-256은 격리 전후와 검사식
정정 전후 모두 동일하다.
