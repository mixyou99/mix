## 6 · ⚠ 03_final 은 완결본이 아니다 — 열린 항목

교수님 판정 **(나)** 에 따라 markdown 만 먼저 승격했다.

| 형식 | 상태 |
|---|---|
| `.md` | ✅ 승격 완료 118건 |
| `.docx` | ❌ **부재** — P1 회수 필터(`.md·.csv·.js·.py`)에 걸려 빠졌다 |
| `.pdf` | ❌ **부재** — 같은 이유 |

2026-08 시험 자산 승격은 `md·docx·pdf` **3형식을 모두** 올렸다.
**따라서 현재 03_final 은 그 기준으로 미완결이다.**

- 강의실 배포에 쓰려면 렌더 산출물이 필요하다. **지금 상태로 배포할 수 없다**
- 2단계(덱 개정)는 markdown 을 읽으므로 **지금 열린다** — 이것이 (나)의 근거다
- **렌더 산출물은 P2 꾸러미(55MB)에 있을 것으로 보인다.** 도착하면 같은 방식
  (바이트 동일 복사·md5 전수 대조)으로 얹어 완결한다. **재렌더는 하지 않는다** —
  이 저장소에서 다시 렌더하면 원본과 바이트가 달라져 승격 규약이 깨진다

**미완결 상태는 `work/CASE_LOG.md` 에도 명시했다.**
