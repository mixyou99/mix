- **사유 컬럼에 "실제 셈"을 숫자로 적을 것.** "맞음"이 아니라 `여섯 = 리뷰수·답변수·답변속도·고객평점하락·누적리뷰수·코로나확진자` 형태
- 오탐(열람·행·열 등)은 사유 컬럼에 `수사 아님`으로 처리하고 남겨 둡니다. 패턴을 좁혀 오탐을 없애려 하지 말 것 —
  좁히는 순간 D-3 같은 건이 다시 빠져나갑니다
