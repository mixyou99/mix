## 3 · 게이트 도구

### `gate_exhibit.py` — Exhibit 게이트 모음 (E-G0·G3·G4·G5·G7·G7R·G8·G9)

```bash
python3 tools/gate_exhibit.py EXHIBITS_KR.docx --pair EXHIBITS_EN.docx \
        --reasons docs/gates/reasons_KR.tsv
```

**docx 우선.** 표 개수·행·셀은 PDF에서 정확히 셀 수 없어, PDF 모드에서는
E-G5(이미지)와 E-G9(등가)가 PASS 대신 **SKIP**이 된다. 보류가 하나라도 있으면
종합 판정은 PASS가 되지 않는다.

**E-G8(수사 스캔)은 사유 열에 판정 토큰을 요구한다** — `일치:` / `수사 아님` / `오류:`.
자유 서술만 있으면 통과하지 않고, `오류:` 가 하나라도 있으면 FAIL이다.
지난 라운드에 사람이 눈으로 찾아낸 D-3(`다섯 표 모두 동일`)을 이 게이트가 잡아낸다.

**E-G9(KR/EN 등가)는 신설이다.** D-4의 EN 문장 누락은 기존 어느 게이트도 잡지
못했다. 판정은 마크다운 마커·서식을 제거하고 공백 정규화한 텍스트에서 한다 —
원문 마크다운에서 세면 언어별 마커 차이로 블록 수가 갈린다.

### `eg7_token_census.py` — 숫자 토큰 전수 대조 (E-G7 단독 실행판)

```bash
python3 tools/eg7_token_census.py EXHIBITS_KR.pdf > docs/gates/EG7_census_KR.md
```

**부호를 문맥으로 판정한다** — 앞 문자가 줄머리·공백·여는 괄호일 때만 부호로 인정.
`COVID-19` 의 하이픈과 `t−1` 의 마이너스를 음수로 읽던 결함을 막는다.
**B·C·D는 음수 계수가 실데이터이므로 이 규칙을 되돌리지 말 것.**

B·C·D 저작 시 회귀계수·SE·Adj R²·그룹수를 화이트리스트와 필수 목록 양쪽에 추가해
그대로 재사용한다.

### `EG7_census_KR.md` · `reasons_KR.tsv` — 현재 KR 판 기준선

R2 이후 재실행 결과와 비교할 대조본. `reasons_KR.tsv` 는 E-G8 사유표의 작성 예시이자
현재 판의 실제 판정(13건 중 오류 1건 = D-3)이다.

### 검사식 정정 원칙

**오탐이 나오면 산출물이 아니라 검사식을 고치고, 정정 이력을 주석으로 남긴다.**
이번 라운드에 두 번 적용했다.

- `**` 단독 매칭이 유의수준 범례 별표(`*** p<0.001`)를 물었다 → 짝을 이룬 형태만 위반으로
- 없는 경로에 대해 "파일 0개"를 보고했다 → 경로를 검증하고 실패는 실패로 보고

두 번째는 이 프로젝트가 계속 다뤄온 실패 유형이다. **오라클이 못 본 것을 없다고 말하면 안 된다.**

### `deck_canon_lms.py` — 판정표 생성기

```bash
find . -name "*.ppt*" -exec stat -f "%Sm|%z|%N" -t "%Y-%m-%d" {} \; | sort > meta.txt
python3 - <<'EOF' > titles.txt   # 각 pptx 의 slide1/slide2 텍스트
# (스크립트 상단 주석 참조)
EOF
python3 tools/deck_canon_lms.py meta.txt titles.txt > DECK_CANON.md
```

다음 학기에도 LMS 목록과 `stat` 출력만 갈아 끼우면 그대로 돈다.

### 판정에 쓴 규칙 — 실측에서 도출

1. **기준 축은 LMS 세션(주제)이다. 주차 번호가 아니다.**
   BUSS215는 10/6 휴강 때문에 실라버스 주차 = LMS 세미나 + 1 (W7 이후).
   KMB689는 특강·휴강이 세미나 번호에 안 들어가 아예 다른 축이다.
2. **파일명이 폴더보다 우선한다.**
   `Seminar 7_Association Rules/` 안에 LRM 파일이, `Seminar 5_Data Management/` 안에
   Review Session이 들어 있다. 폴더만 보면 틀린 파일이 정본으로 뽑힌다.
3. **배포본과 수업본은 계보가 다르다.**
   배포본(접미사 없음·`_Updated`)이 개정 출발점. 수업본(`_InClass`+순번+학기)은
   강의실 운영용이라 그 학기 일정·복습·공지가 섞인다. 다만 업데이트가 수업본에만
   남았을 수 있어 대조 대상으로 함께 싣는다.
4. **재활용 원본을 분리한다.**
   슬라이드 1장이 EMBA114(성균관대)·BUS930·BUSS305·KMB581이라고 밝히는 12개.
   날짜만 보면 최신판으로 뽑히지만 다른 과목 자료다. 버리지 않고 참고용으로 보존.
5. **실습 전용 세션은 결손이 아니다.**
   R 코드 위주로 진행하고 슬라이드에는 연습문제만 싣는 7개 세션. 강의 덱이 없는 것이 정상.

**이름 규칙은 늘 지켜지지 않는다.** 그래서 자동 판정을 확정으로 표시하지 않고,
규칙과 실측이 어긋나는 6건만 `⚠` 로 표시했다. 그것만 파일을 열어 보면 된다.
