## [AI 분석 보고서] "광고 예산 확대 시 매출 예측"

### 1. 요약 (Executive Summary)

일별 광고비와 일별 매출은 **매우 강한 선형 관계**를 보입니다(R² = 0.96). 광고비 1만원 증가는 매출 **약 0.92만원 증가**와 연결됩니다.

이 관계를 이용해 예측한 결과, **광고비를 현재 상한인 50만원/일에서 200만원/일로 4배 늘리면, 매출은 약 54만원/일에서 약 192만원/일로 약 3.6배 증가**할 것으로 예측됩니다.

**권고: 광고 예산을 일 200만원까지 확대할 것.** 모형의 설명력이 96%로 매우 높아 예측의 신뢰도가 충분합니다.

### 2. 분석에 사용한 R 스크립트

```r
# ────────────────────────────────────────────────
# [구역 1] 데이터 적재 및 전처리
# ────────────────────────────────────────────────
raw   <- read.csv("daily_ads_sales.csv", stringsAsFactors = FALSE)
raw   <- raw[!is.na(raw$ad_spend) & !is.na(raw$sales), ]
raw$ad_spend <- as.numeric(gsub(",", "", raw$ad_spend))
raw$sales    <- as.numeric(gsub(",", "", raw$sales))
ads   <- raw[order(raw$ad_spend), c("ad_spend", "sales")]

# ────────────────────────────────────────────────
# [구역 2] 모형 적합 및 예측 — 결과 산출부
# ────────────────────────────────────────────────
model <- lm(sales ~ ad_spend, data = ads)
summary(model)

new_budget <- data.frame(ad_spend = c(50, 100, 150, 200))
pred       <- predict(model, newdata = new_budget)
print(pred)

plot(ads$ad_spend, ads$sales,
     xlab = "일일 광고비 (만원/일)", ylab = "일일 매출 (만원/일)")
abline(model, lwd = 2)
lines(c(50, 200), predict(model, data.frame(ad_spend = c(50, 200))),
      lty = 2, lwd = 3, col = "steelblue")
```

*구역 1은 AI가 수행한 데이터 정리 작업이다. 구역 2가 **결과를 산출하는 결정적 코드**이며, 감사 노력은 여기에 집중한다.*

## [학생용] 이 보고서를 그대로 올려도 되는가?

이 보고서는 유창하다. 실제 데이터로 실제 회귀를 돌렸고, 계수도 예측값도 계산 오류가 없다. R²가 0.96이라는 것도 사실이다. 표도, 그림도, 권고도 모두 자신감 있게 제시돼 있다.

**그러나 관리자는 여기서 검증을 시작한다.**

옆의 **검증 워크시트**를 사용해 **STAR 4단계** — 기준(S) → 시킴(T) → 검증(A) → 결정(R) — 로 이 산출물을 감독하라. 오늘 블록1에서 배운 **서술 vs 예측**의 구분과, Wk3에서 배운 **결과 읽기 3원칙**(축·표본·불확실성)이 도구다.

특히 다음을 물어라.

1. AI가 내놓은 주장은 **서술(descriptive)** 인가 **예측(predictive)** 인가? 둘이 섞여 있지는 않은가?
2. 이 예측을 지탱하는 **가정**은 무엇이며, **데이터는 그 가정을 지지하는가**?
3. R 스크립트의 **구역 2**에서 AI가 예측을 요청한 **지점(광고비 값)** 은 어디인가? 그 지점은 **데이터가 있는 곳인가**?
4. R²가 0.96이라는 사실은 **무엇에 대한** 설명력인가? 그것이 이 권고를 지지하는가?

**활동 규칙 (AI 사용)**: 먼저 자신의 기준과 1차 판단을 기록한 뒤, 단계 3 이후에는 AI에게 질문할 수 있다. 다만 AI의 답도 정답이 아니라 다시 감사해야 할 산출물로 취급한다. 최종 결정문은 반드시 학생 본인이 작성한다.

---

*※ 이 사례의 광고비-매출 데이터는 **서술 vs 예측 개념을 설명하기 위한 교육용 가상 데이터**이며, 실제 기업 데이터가 아니다. 회귀 계수·예측값·R²는 이 가상 데이터에서 실제로 계산된 값이다. 검증 대상은 데이터의 진위가 아니라 **AI의 해석과 권고**다.*
