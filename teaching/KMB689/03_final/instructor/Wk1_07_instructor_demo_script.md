## ⚠ DF-1 · 학기마다 해야 할 일 — 기준일 갱신

시연 데이터는 **기준일 2026-07-17** 기준이다. 다음 학기에 그대로 쓰면 "487일 전"이 "800일 전"으로 읽히고, "6일 전"이 "300일 전"이 된다. **매 학기 갱신한다.**

### 권장 방법 — 날짜 일괄 이동

**모든 주문 날짜와 기준일을 같은 일수만큼 뒤로 민다.** 이 방법은 경과일(R)·주문 건수(F)·누적 금액(M)이 **전부 그대로 보존**되므로, 검증된 시연 속성(교집합 0/5, 변별력, 두 명단)이 **재검증 없이 유지**된다.

```python
# 예: 수업일이 2027-03-05인 경우
import pandas as pd
from datetime import date

OLD = date(2026, 7, 17)      # 현재 기준일
NEW = date(2027, 3, 5)       # 새 수업일(또는 학기 시작일)
shift = (NEW - OLD).days

for f in ["Wk1_orders.csv", "Wk1_customer_summary.csv"]:
    d = pd.read_csv(f)
    col = "order_date" if "order_date" in d else "last_order"
    d[col] = (pd.to_datetime(d[col]) + pd.Timedelta(days=shift)).dt.strftime("%Y-%m-%d")
    d.to_csv(f, index=False)
print("새 기준일:", NEW, "| 이동일수:", shift)
```

**갱신 후 반드시 고칠 것**

| 위치 | 고칠 내용 |
|---|---|
| `Wk1_03_demo_exhibit_STUDENT` | 표 위 **"기준일: 2026년 7월 17일"** · 표의 최종 주문일 14개 · 보고서 A/B 작성일 |
| `Wk1_03_demo_exhibit_INSTRUCTOR` | 검산 예시의 날짜 계산 |
| `Wk1_07_instructor_demo_script` (이 문서) | S2 참고 계산의 날짜 |
| 데이터 기간 서술 | "2025년 1월 ~ 2026년 7월" → 새 기간 |

**변하지 않는 것** (재검증 불필요): 경과일·주문 건수·누적 거래액·두 TOP5 명단·교집합 0.

⚠ **생성기(`Wk1_data_generator.py`)를 새 기준일로 다시 돌리지 말 것.** 난수 날짜가 새로 뽑혀 검증된 6항목을 **처음부터 다시 측정**해야 한다. 일괄 이동이 안전하다.
