인턴이 승인된 사내 AI 환경에 유튜브 리뷰 영상 데이터를 올리고 다음과 같이 요청했다.

AI는 몇 초 만에 R 스크립트를 실행하고 아래 보고서를 만들어 왔다. **인턴은 이걸 그대로 캠페인 계획에 올려도 되는지 당신에게 묻고 있다.**

## [AI 분석 보고서] "리뷰 채널 지형과 좋아요 동인"

### 1. 요약 (Executive Summary)

리뷰 채널 데이터를 분석한 결과, **전형적인 채널은 영상당 평균 약 5,300개의 좋아요**를 받습니다. 좋아요는 **채널 규모(조회수·구독자)와 강하게 연결**되어 있으며(Pearson r = 0.64), 큰 채널일수록 좋아요가 많습니다.

**권고: 큰 채널에 협업을 집중하세요.** 채널 규모가 좋아요를 강하게 끌어올리므로, 규모가 큰 채널과 협업하면 캠페인 반응을 극대화할 수 있습니다.

### 2. 요약 통계

| 지표 | 값 |
|---|---|
| 평균 좋아요 (영상당) | **5,300** |
| 평균 채널 조회수 | 1억 4,059만 |
| 좋아요 × 채널 조회수 상관 (Pearson) | **0.64** |

### 3. 분석에 사용한 R 스크립트

```r
# ────────────────────────────────────────────────
# [구역 1] 데이터 적재 및 전처리
# ────────────────────────────────────────────────
raw <- read.csv("channels.csv")
cat("원본 데이터:", nrow(raw), "행\n")     # 원본 데이터: 2075 행
num <- raw[, c("likeCount","channelViewCount","subscriberCount",
               "viewCount","relevent","duration")]

# ────────────────────────────────────────────────
# [구역 2] 결측 처리 및 분석 — 결과 산출부
# ────────────────────────────────────────────────
clean <- na.omit(num)                       # 결측 있는 행 제거
cat("분석 데이터:", nrow(clean), "행\n")    # 분석 데이터: 1938 행

mean_like <- mean(clean$likeCount)
print(mean_like)                            # [1] 5300.3

r <- cor(clean$likeCount, clean$channelViewCount)
print(r)                                    # [1] 0.639

plot(clean$channelViewCount, clean$likeCount, log = "xy")
```

*구역 1은 데이터를 읽어 필요한 열을 고르는 작업이다. 구역 2가 **결과를 산출하는 결정적 코드**이며, 감사 노력은 여기에 집중한다.*

### 5. 최종 제언 (AI)

> "데이터는 명확합니다. 전형적인 채널이 영상당 5,300개의 좋아요를 받고, 채널 규모와 좋아요의 상관이 0.64로 강하므로, **큰 채널에 협업을 집중**하는 것이 캠페인 반응을 극대화하는 길입니다."

## [학생용] 이 보고서를 그대로 캠페인에 쓸 수 있는가?

이 보고서는 유창하다. 실제 데이터로 실제 계산을 했고, 평균도 상관도 계산 오류가 없다. R 스크립트도 정상 작동했다. 표도, 그림도, 권고도 분명하다.

**그러나 관리자는 여기서 검증을 시작한다.**

옆의 **검증 워크시트**로 **STAR 4단계** — 기준(S) → 시킴(T) → 검증(A) → 결정(R) — 를 수행하라. 오늘 블록1에서 배운 **요약 읽기 체크리스트**(N → 중심 → 퍼짐 → 극단)와 **상관 읽기 질문**이 도구다.

특히 다음을 물어라.

1. AI가 보고한 숫자들은 **몇 행**에 대한 것인가? 스크립트에서 **원본 N과 분석 N**을 찾아 비교하라.
2. 두 N이 다르다면, **어떤 행이 사라졌는가?** 사라진 행은 무작위인가?
3. "평균 좋아요 5,300"은 **전형적인 채널**을 대표하는가? 중앙값은 어디 있는가?
4. 상관 0.64는 **전체**의 이야기인가, **몇 점**의 이야기인가?

**활동 규칙 (AI 사용)**: 먼저 자신의 기준과 1차 판단을 기록한 뒤, 단계 3 이후에는 AI에게 질문할 수 있다. 다만 AI의 답도 정답이 아니라 다시 감사해야 할 산출물로 취급한다. 최종 결정문은 반드시 학생 본인이 작성한다.
